💡 How to set class racing order:
1. Check the classes you want in this event
2. Selected classes will move to the top and show ⋮⋮ drag handles
3. Drag the handles to reorder classes
4. This order determines how classes appear in races!

Free Run Enabled: Fill races to maximum capacity first, creating fewer total races.
Free Run Disabled: Balance the last races so no one gets a "bye" or free pass.
