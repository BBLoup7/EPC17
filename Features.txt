EPC17 — Feature List 
Core Event Management

Registration system

Add / edit / remove participants

Validation of driver entries (unique IDs, class rules, duplicates)

Tech Sheet planned but not implemented yet

Total amount due is tracked per participant (no payment tracking system)

Series & Season Management

Supports multiple series

Each series can include multiple seasons

Events can be linked to a season

Event configuration

Define event metadata (date, tracks, classes)

Set number of eliminations (customizable)

Choose bracket type: single, double, custom, or “no bracket”

Unique final or multiple finals supported

Class management

Prevent scheduling conflicts for multi-class drivers

Configurable class properties per event

Pairing & Race Logic

Pairing engine

Rematch avoidance (don’t repeat opponents until all matchups are cycled)

Lane assignment optimization (least-used first, recency as tie-breaker)

Free run handling for odd participant counts

Bracket generation

Customizable elimination formats (single, double, or user-defined)

Configurable finals (unique or multiple)

Option to run events with or without brackets

Race management

Real-time race result entry

False start + disqualification (DSQ) support

Automatic save of results and state after every operation (no crash recovery needed since state is always saved)

Live Display (Spectators)

Big-screen display for heats, results, and lane assignments

PNG and PDF export of brackets and results

No SMS or email delivery system yet

Analytics & Reporting

Driver-level results stored per event

Event-level reports exportable to PDF or PNG

No championship standings system implemented (not planned for now)

Data & State

Persistent JSON storage for participants, events, and races

Automatic save on every operation (no manual “save” step)

UUID-based identifiers for collision-free operations

Backup files generated to protect against corruption

User Interface

Responsive design (desktop and mobile friendly)

Event staff oriented layout (simplified navigation, minimal clutter)

Real-time updates without page refresh

Accessibility basics (semantic HTML, keyboard navigation, ARIA where relevant)
