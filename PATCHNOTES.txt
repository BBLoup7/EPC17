# EPC17 Patch Notes

## Version D0L9R6 (Released)
Version D0L9R6 delivers comprehensive data integrity fixes and advanced pairing algorithms, resolving critical issues with participant duplication, race bracket corruption, and UI synchronization while introducing intelligent race spacing and incomplete race limitation features to ensure fair competition and system stability.

This release repaired 2,775 duplicate participant assignments across 8 events, eliminated race bracket duplication causing 404 errors, and enhanced the pairing engine with class spacing logic and incomplete race tracking to optimize tournament fairness and data reliability.

- **CRITICAL FIX**: Fixed race bracket duplication and 404 errors causing console spam and data corruption
  - ✅ Added automatic bracket ID generation for brackets missing IDs to prevent duplicates
  - ✅ Implemented save queue to prevent concurrent bracket saves for the same event
  - ✅ Enhanced cleanupDuplicateBrackets to handle 404 errors gracefully (brackets already deleted)
  - ✅ Fixed bracket initialization in race.js to include unique ID from creation
  - ✅ Added proper error handling for DELETE operations during cleanup

- **UI FIX**: Fixed visual glitch during race completion where positions briefly showed incorrect values (1st/2nd appeared empty, 3rd appeared as 1st) for 1-2 seconds when selecting 3rd place finisher. ## Version D0L10R1 (Beta)
- **Fixed Position Assignment Logic**: Fixed race position assignment in races.html to be purely click-order based: first driver clicked gets 1st place, second gets 2nd place, etc. Clicking an already-assigned driver unassigns them. Removed duplicate event handlers that were causing conflicting position assignments.
- **Fixed Race Auto-Completion**: Fixed inconsistent auto-completion behavior when false starts are marked before or after position assignments. Now uses consistent logic regardless of operation order.
- **Fixed Driver Swap Bug**: Fixed critical bug where right-clicking to swap drivers multiple times would cause driver duplication and deletion. Enhanced validation to check for duplicates across entire bracket and added cache synchronization to prevent race conditions during rapid operations.
- **Enhanced Bracket Data Repair**: Improved automatic detection and repair functionality for corrupted bracket data. The repair function now fixes both duplicate participants AND incorrect heat round assignments, ensuring complete data integrity restoration.
- **Added Round Debug Tool**: Added "Debug Rounds" button to help troubleshoot round-related swap issues. Shows detailed information about which round each heat belongs to, helping users understand why cross-round swaps are blocked.
