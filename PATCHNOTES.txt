# EPC17 Patch Notes

## Version D0L10R1 (Beta)
- **Fixed Position Assignment Logic**: Fixed race position assignment in races.html to be purely click-order based: first driver clicked gets 1st place, second gets 2nd place, etc. Clicking an already-assigned driver unassigns them. Removed duplicate event handlers that were causing conflicting position assignments.
- **Fixed Race Auto-Completion**: Fixed inconsistent auto-completion behavior when false starts are marked before or after position assignments. Now uses consistent logic regardless of operation order.
- **Fixed Driver Swap Bug**: Fixed critical bug where right-clicking to swap drivers multiple times would cause driver duplication and deletion. Enhanced validation to check for duplicates across entire bracket and added cache synchronization to prevent race conditions during rapid operations.
- **Enhanced Bracket Data Repair**: Improved automatic detection and repair functionality for corrupted bracket data. The repair function now fixes both duplicate participants AND incorrect heat round assignments, ensuring complete data integrity restoration.
- **Added Round Debug Tool**: Added "Debug Rounds" button to help troubleshoot round-related swap issues. Shows detailed information about which round each heat belongs to, helping users understand why cross-round swaps are blocked.
