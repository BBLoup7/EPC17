## Version D0L12R2.5 (Patch)

### Large Dataset Performance Optimization
- Reworked backend list APIs to use SQL-level pagination/filtering instead of loading whole tables in memory:
  - `/api/participants` now uses paginated DB queries with bounded limits.
  - `/api/events` now uses paginated DB queries with bounded limits and allowed-event scope filtering.
  - `/api/race-brackets` now returns lightweight metadata for list views and full bracket payload only for `eventId` queries.
- Race stats stability fix for metadata-only bracket cache entries:
  - `utils/data-manager.js#getRaceBracket()` now treats cached brackets as usable only when they include `classes`; metadata-only cache hits are bypassed and replaced by an event-scoped fetch (`/api/race-brackets?eventId=...`) that returns full bracket payload.
  - Event-scoped bracket responses are now cached by both `eventId` and bracket `id` to prevent fallback paths from reusing metadata-only records.
  - This resolves `TypeError: Cannot convert undefined or null to object` in `RaceManager.getTournamentStats()` when selecting events after metadata-first list loads.
- Regression fix: restored a missing JSDoc opener above `getRaceBracket()` that caused `Unexpected identifier 'race'` and prevented `DataManager` from loading on `races.html`.
- Debug instrumentation cleanup: removed temporary debug POST probes from `js/race-ui.js`, `modules/race.js`, and `utils/data-manager.js` after runtime verification confirmed the race event selection issue is fixed.
- Added runtime/permanent DB indexes and new aggregation/count query methods in `utils/db_manager.py` to reduce full scans and expensive JSON-heavy loads.
- Optimized `/api/health` to use count queries instead of fetching full entities.
- Reduced analytics N+1 patterns:
  - `/api/stats/event/<event_id>` now queries event participants directly.
  - `/api/stats/driver/<driver_id>` now fetches only brackets relevant to that driver.
  - `/api/stats/time` and `/api/stats/series/<series_id>` now batch participant/bracket retrieval instead of reloading full datasets per event.
- Frontend data-loading improvements:
  - `utils/data-manager.js` now defaults `getParticipants()`/`getEvents()` to server-side pagination and increased cache TTLs for high-volume usage.
  - `existing-drivers.html` now uses server-paginated driver loading with debounced search and prev/next controls.
  - `driver-profile.html` now uses server-side driver search for selector population instead of unbounded preload.
  - `event-analytics.html` now lazy-loads participants/brackets per selected event instead of preloading huge global datasets.
  - `modules/registration.js` now paginates participant list rendering and uses API-compatible class filtering.
  - `modules/event-data-service.js` now batches participant lookup via map before fallback single lookups.
  - `events.html` removed the 10k event fetch pattern and uses a bounded request.
  - *Files*: `utils/db_manager.py`, `server.py`, `utils/data-manager.js`, `existing-drivers.html`, `event-analytics.html`, `driver-profile.html`, `modules/registration.js`, `modules/event-data-service.js`, `events.html`, `PATCHNOTES.txt`

## Version D0L12R1.0 (Major Release - Comprehensive System Update)

**Summary**: This major release represents a significant milestone for EPC17, consolidating months of development into a stable, feature-rich platform for professional race management. It includes a complete overhaul of the user interface, robust backend improvements, enhanced analytics, and a refined pairing engine.

### 🌟 Core Features
- **Deterministic Pairing Engine**:
  - Guaranteed rematch avoidance until necessary.
  - Intelligent lane balancing and bye-run handling.
  - Tie-breaker race generation for ranking resolution.
- **Advanced Event Management**:
  - Support for multi-class events with custom rules.
  - Series management for championship tracking.
  - "Late Driver Injection" for adding participants mid-event.
- **Robust Registration System**:
  - Full CRUD for participants with tech sheet support.
  - Unified "Driver Edit Form" for consistent data management.
  - Optimized data loading for large participant lists.

### 🎨 UI/UX Overhaul
- **Modern Design System**:
  - Complete visual refresh with consistent spacing, typography, and color palette.
  - Glassmorphism effects, animated transitions, and polished component libraries.
  - Mobile-responsive layout with touch-optimized targets.
- **Enhanced Interactions**:
  - Non-blocking race result processing for faster workflows.
  - Toast notification system for user feedback (z-index fixed).
  - Improved sidebar navigation with "Access Denied" handling.

### 📊 Analytics & Reporting
- **Centralized Analytics Engine**:
  - Unified computation layer for event, series, and driver stats.
  - Ad-blocker bypass fix (API renamed to `/api/stats`).
- **Visualizations**:
  - Interactive charts for win rates, lane bias, and class distribution.
  - "Driver Profiles" with deep-dive performance metrics.
- **Data Integrity**:
  - Correct handling of completed event brackets in analytics.
  - Fix for stress test data generation structure.

### 🔧 Backend & Architecture
- **Persistence Layer**:
  - SQLite-backed session management (persists across restarts).
  - UUID-based ID system for reliable data tracking.
  - Automatic backups and migration utilities.
- **Performance**:
  - Optimized data fetching (lazy loading, batched requests).
  - "DebugLogger" system for reduced console noise.
  - Refactored event data services to prevent circular dependencies.

### 🔒 Security & Permissions
- **Role-Based Access Control (RBAC)**:
  - Granular permissions (Events, Races, Admin, etc.).
  - Secure session handling with expiry cleanup.
  - Graceful 403 error handling and redirection.

### 🐛 Key Bug Fixes
- **Race Logic**:
  - Fixed "Swap Same Heat" validation scope.
  - Resolved "Brackets already initialized" error blocking generation.
  - Corrected handling of duplicate participants in bracket generation.
- **System Stability**:
  - Fixed stack overflow in event class activation.
  - Resolved missing bracket data for synthetic events.
  - Fixed `console.debug` crash in older browsers/contexts.
